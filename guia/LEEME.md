# Guías con capturas

Una guía por servicio, paso a paso. Las siguen el usuario y Claude durante la entrevista (`CONFIGURAR.md`) y la instalación (`INSTALAR.md`); los guiones enlazan aquí y no repiten estos pasos.

Las capturas están en `guia/img/`. Llevan marcado en rojo dónde hacer clic y tapado lo que es privado; algunas son ilustraciones, y lo dicen. Los textos de las guías no repiten lo que ya dice la captura: si algo cambia en un servicio, cambia la captura y el texto de esa guía.

| Guía | Para qué | Cuándo |
|---|---|---|
| [claude-code.md](claude-code.md) | Abrir tu repositorio en Claude Code (entrevista en la nube e instalación en tu PC) | Entrevista e instalación |
| [neon.md](neon.md) | Crear la base de datos y copiar la conexión y el Project ID | Instalación, paso 3 |
| [telegram.md](telegram.md) | Crear el bot que te envía los CV | Instalación, paso 4 |
| [energia-windows.md](energia-windows.md) | Que el PC no se suspenda durante la captura | Instalación, paso 6 |
| [github.md](github.md) | Secretos de la Action y token para la rutina | Instalación, pasos 7 y 8 |
| [conector-neon.md](conector-neon.md) | Conectar Neon a Claude como conector personalizado (rutina y bot) | Instalación, paso 8 |
| [rutina.md](rutina.md) | Crear la tarea programada diaria de CV | Instalación, paso 8 |
| [bot.md](bot.md) | Montar el bot de gestión (opcional) | Instalación, paso 9 |
